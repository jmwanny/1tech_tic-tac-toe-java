# 🎮 Tic Tac Toe Java Game

A Tic Tac Toe desktop game built in **Java** using Object-Oriented Programming concepts as a BSIT 2nd Year project.

---

## ✨ Features
- Player vs Player mode
- Player vs AI mode
  - Easy
  - Medium
  - Hard
- Choose X or O
- Instructions screen
- Background music
- Mute / Unmute toggle
- Clean interface
